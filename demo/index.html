📘 怎么玩 · 使用说明

moxwebgpu 把计算下推到你的浏览器：打开网页，网页就用你电脑里的 GPU 做并行计算。服务器只发一个网页，数据全程不离开你的机器。

🎛️ 第一步 · 切换 GPU / CPU

  • 顶部中间的开关：GPU ⇄ CPU 一键切换。同一份计算，GPU 模式下右上角的 帧率 (fps) 会明显更高、画面更顺。
  • 开关旁边的 ms/帧 是单帧耗时，数值越低越快。

🧩 第二步 · 选一个画面

  • ✨ 粒子几万到几十万个粒子每帧迭代，轨迹累加成密度图。把「粒子数 / 每帧步数」拉满，差距最夸张。
  • 🌀 分形每个像素独立做逃逸迭代。把「迭代上限」拉到 800，一帧就是数亿次运算。
  • 🖼️ 卷积非分离 2D 卷积（模糊/锐化/边缘/浮雕）。核开到 31×31，单帧 4.8 亿次乘加。
  • 🎞️ 视频页面里有一个正在播放的视频，GPU 对每一帧实时做滤镜。可上传你自己的视频。

🎚️ 第三步 · 拖滑杆、传文件

  • 拖动面板里的滑杆，画面实时变化。
  • 🖼️ 卷积 和 🎞️ 视频 都能点按钮用你自己的图片 / 视频。
  • 「暂停 / 继续」「重置」随时控制；右下角是视频源小窗。

🌐 在哪能跑

  • ✅ Chrome / Edge 113+
  • ✅ 安卓 Chrome
  • ✅ 部分 Firefox / Safari（需开启 WebGPU 实验开关）
  • ⚠️ 不支持的浏览器会自动降到 CPU 模式（功能一样，只是慢）。
  • ⚠️ 需要在 https 或 localhost 安全上下文下打开。

⚡ 技术说明

  • 纯前端、零后端、零数据上传。GPU 计算由 moxwebgpu 框架驱动（WebGPU 通用计算 / GPGPU）。
